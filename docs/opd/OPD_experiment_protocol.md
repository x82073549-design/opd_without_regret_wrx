# OPD 特征有效性验证实验指引

本指引规定如何在 token、样本、teacher 三个粒度上验证某一特征（或特征组合）对 On-Policy Distillation (OPD) 的有效性，
并给出统计显著性的判定方法。目标是识别在三个粒度上均有效、且作用方向一致的特征组合。

## 0. 目标与成功判定

**目标**：找到一个特征（或复合特征），其取值能在 token 加权、样本选择、teacher 选择三类操作中提供一致且可操作的指导。

**成功判定**（须同时满足）：
1. 在三个粒度上各自的干预效应均达到统计显著；
2. 三个粒度上的有效方向一致（高特征值 → 更高投入）；
3. 三个粒度尽量采用同一种操作化定义（即「统一特征」条件，而非三个互不相关的特征各自有效）；
4. 在各粒度上不弱于该粒度的现有最强基线（token：TIP / FiRe；样本：PACED / FiRe 轨迹过滤；teacher：固定最优 / BRTS）。

---

## 1. 通用方法学（三个粒度共用）

### 1.1 因变量

- **筛选阶段**：held-out 集上学生对 teacher 的 reverse-KL。方差低、计算快，适合大批量候选特征的初筛。
- **确认阶段**：held-out 集上的准确率（avg@k）。作为对外报告的主指标。

两阶段须事先固定，且全程使用同一 held-out 集，以保证跨粒度结果可比。

### 1.2 复制单元与显著性检验

单次训练存在 run 间噪声，单一 run 的差异不构成证据。须从两个来源引入复制：

- **训练噪声**：每个实验条件运行 R 个随机种子（建议 R = 3–5）。
- **评测噪声**：以 avg@k 评测，并对 held-out 题目做自助法（bootstrap）。

对应两类检验：
- **跨种子组间检验**：每条件得到 R 个指标值，用 Mann–Whitney U 检验或双样本 t 检验，并报告均值 ± 标准差与效应量（Cohen's d 或秩双列相关）。R 较小时 p 值统计力有限，须辅以效应量与负对照的单调序作为佐证。
- **评测集配对检验**：对两条件的最优 run，在同一 held-out 集上做配对自助法（同题、配对，报告 Δ 与 95% CI），或对逐题对错做 McNemar 检验。

### 1.3 负对照

仅比较「干预 vs 均匀」会与「任何非均匀操作的副作用」混淆。须引入负对照：
- **取反特征**：在特征指示「应增加投入」处反而减少投入。预期表现最差。
- **随机对照**：保持操作分布形状但打乱其与特征的对应关系。用于区分「特征排序是否重要」与「操作分布形状是否重要」。

判定特征带有效信息的标志，是 `取反 < 均匀/随机 < 正常` 的单调序在统计上成立。

### 1.4 门控分层

OPD 信号的有效方向随学生是否已掌握而变化（Unmasking OPD：信号在学生答错的 rollout 上与理想梯度的对齐度更高）。
因此所有粒度的分析均须按「学生 rollout 是否正确」分层进行，避免正负效应相互抵消。

### 1.5 混淆控制

- 特征间高度共线（如熵、散度、位置相关）。须用多元回归或逐步消融评估目标特征的边际贡献，避免归因错误。
- 接近性能上限时效应量被压缩。须选取具备 headroom 的设定（较早的 checkpoint、足够困难的题目）。
- 至少在两个 checkpoint（如训练早期与中期）各验证一次，以检验结论对训练阶段的稳健性。

## 2. Token 级

### 2.1 设计

从同一 checkpoint 出发，固定预算与种子集，比较以下条件（二选一实现）：

- **掩码实现**：仅在选中 token 上计算损失。条件为 top-x% / 随机 x%（等量）/ bottom-x%。
- **软加权实现**：正常加权 / 取反加权 / 均匀，并附随机打乱权重对照。

### 2.2 关键控制

- 取反与正常之间**唯一的差异应为权重在 token 间的分配，而非总梯度幅度**。须将权重归一化以保持总梯度量不变（参照 FiRe 的权重归一化）。
- 加权强度（如 α）与效应量耦合。比较不同特征时须在对齐的（或各自最稳定的）强度下进行，建议报告一段强度范围上的曲线下面积，而非单点。

### 2.3 判定

- 预期单调序：`bottom / 取反 < 随机 / 均匀 < top / 正常`。
- 显著性：跨种子组间检验（top vs random、top vs bottom）+ 评测集配对自助法；按学生正确性分层各做一次。
- **可实现增益**应以「正常 vs 均匀（或随机）」衡量；「正常 vs 取反」的摆幅会高估上界，仅作下界 sanity check。
- 有效性的最终门槛为不弱于 TIP / FiRe，而非仅优于取反。

---

## 3. 样本级

### 3.1 设计

按样本级特征值将训练池分为 high 与 low 两端，各取等量样本；另设等量随机子集作为中性对照。三组各运行 R 个种子。

### 3.2 关键控制

- **三组的样本量与计算量必须完全对齐**。不得以子集与全集比较，否则差异将与数据量混淆。
- 若采用「训练至收敛」，须注意不同子集收敛点与过拟合风险不同；固定预算 + 多种子通常更易保证可比性。

### 3.3 方向陷阱

以单一「teacher 置信度」选择样本，可能选中「teacher 笃定且学生已掌握」的饱和样本，其价值低（对应 CoDaPO 的简单题、Unmasking OPD 的「学生已掌握处信号偏噪」）。
故须任选其一：
- 附加门控，仅保留「学生尚未答对」的样本；或
- 直接以复合特征「teacher 置信 × 学生未掌握」作为被验证对象。

### 3.4 判定

- 预期序：`high > 随机 > low`。
- 显著性：跨种子组间检验；若特征与难度相关，须按难度分箱在箱内复核，排除难度主导。

---

## 4. Teacher 级

### 4.1 真值排序（不可省略）

teacher 选择的有效性须对照独立真值，否则构成循环论证。
选取 3–4 个候选 teacher，从同一学生 checkpoint 出发，**对每个 teacher 各运行一段短 OPD**，测 held-out 增益，得到该学生下 teacher 的真实优劣排序。teacher 数量宜少、单次运行宜短以控制开销。

### 4.2 特征预测

在 probe 集上、不进行训练，计算 teacher 选择特征，对候选 teacher 给出预测排序。

### 4.3 复制单元与显著性

候选 teacher 数量少，单次秩相关统计力不足。**复制单元应为 (学生, 任务) 设定**，须覆盖多个设定，并采用：
- **命中率检验**：特征选出的首位 teacher 是否为真实首位，跨设定统计命中率，对照随机基线 1/m 做二项检验；或汇总多设定的秩相关（Spearman / Kendall）+ 置换检验。
- **端到端确认**：「按特征选择的 teacher 训练」对照「随机 teacher」（可再加「按取反特征选择」），跨设定与种子做配对检验。

### 4.4 方向约束

不得以「teacher 强度 / 置信度」作为选择特征。RethinkingOPD 表明 teacher 基准分数高不等于对 OPD 有用；有效 teacher 须同时满足与学生思维兼容（overlap 充分）与提供学生尚不具备的新能力。
选择特征应至少编码上述两者，例如 `overlap × (teacher 正确 ∧ student 错误) 的比例`。

### 4.5 分阶段执行

- 先验证「为该学生选择单一最优 teacher」（开销低，验证特征能否预测 teacher 优劣）。
- 通过后再进入 per-sample 路由（不同样本分配不同 teacher），后者为「teacher 作为独立粒度」的主要贡献点。

---

## 5. 跨粒度一致性（统一特征判定）

在三个粒度各自验证完成后，须检验是否为同一信号在起作用，而非三个独立特征各自有效：

1. **方向一致**：三个粒度上「高特征值 → 更高投入」均为有效方向。
2. **操作化一致**：三个粒度尽量采用同一特征定义与同一作用方向。
3. **联合优于最强单粒度方法**：以同一特征联合驱动三个粒度的操作，应优于仅使用任一粒度的最强专用方法。该条为相对现有工作（如仅覆盖两粒度、且使用两个特征的 FiRe）的主要区分点。

---

## 6. 推荐执行顺序

按由廉至贵、fail-fast 推进：

1. **Token 级**（最廉）：掩码 / 加权 + 负对照，确认特征带方向性信息。
2. **样本级**：等量 high / low / 随机三组，确认样本选择的判别力。
3. **Teacher 级**（最贵）：先单一最优、后 per-sample 路由，对照真值排序。

**最小起步版本**：单一 (学生, teacher) 对、单一 checkpoint、约 500 题，埋全 Tier-1 特征与学生正确性，先完成 Token 级与样本级。该步即可回答两个核心问题——复合特征是否优于其原始单量、门控是否必需——再决定是否投入 teacher 级与确认阶段训练。

| Token | top-x% / 随机 x% / bottom-x%（或正常 / 取反 / 均匀加权 + 随机打乱） | 等量 token、同预算、归一化总梯度、对齐加权强度 | reverse-KL（筛）→ accuracy（确认） | 跨种子组间 + 评测配对自助法，按正确性分层 |
